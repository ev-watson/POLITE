the current observatory-control flow.

- `night_session_20260302.py` — dated sensor-characterization night session for
  the **SBIG STX-16803 CCD era** (Julian, CA, 2026-03-02). Hardware, filter set
  (`Clear/Red/Blue/Green/Halpha`), and the internal guide chip predate the
  QHY268M / ZWO EFW / INDIGO migration. For new sessions generate a fresh script
  with `scripts/new_night_session.py` (which now targets the QHY/EFW/Pyxis
  Alpaca config).
